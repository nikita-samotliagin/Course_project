# Пульс заказов

Учебное одностраничное приложение статистики заказов интернет-магазина. Стек: Python 3.12, Flask 3.1.3, SQLite, HTML5, CSS3, JavaScript. Три графика рисуются непосредственно Canvas 2D, без библиотек диаграмм.

## Запуск на Windows

Нужен установленный Python 3.12 x64. Распакуйте весь каталог, запустите demo.bat и откройте http://127.0.0.1:5065. При первом запуске создаются локальное окружение, база и демонстрационные записи. Зависимости находятся в vendor/wheels; подключение к сети для их установки не нужно. Команда py -3.12 должна быть доступна. Если её нет, установите Python 3.12 с Python Launcher.

Учебные аккаунты: admin@example.test и analyst@example.test. Пароль обоих: DemoPass2026! Эти аккаунты предназначены для локальной демонстрации. Собственная регистрация создаёт аналитика с правом чтения.

start.bat запускает экземпляр без автоматического заполнения. Для отдельного ручного запуска:

```powershell
py -3.12 -m venv --without-pip .venv
.venv\Scripts\python.exe setup_offline.py
.venv\Scripts\python.exe manage.py migrate
.venv\Scripts\python.exe manage.py seed
.venv\Scripts\python.exe manage.py run
```

seed откажется работать, если пользователи уже существуют. Остановка: Ctrl+C. База и ключ сессии хранятся в instance. Перед заменой файлов сделайте копию этого каталога. Готовая база и ключ сессии не входят в архив.

## Возможности и значения показателей

Обзор содержит сумму выполненных заказов, количество заказов, средний чек выполненных заказов и количество единиц выполненных позиций. Фильтры: даты включительно, категория, канал, статус. Период ограничен 366 днями. Сумма считается только для статуса delivered по дате создания заказа. Возвраты и отмены не вычитаются из общего оборота, а полностью исключаются. Это учебная оперативная статистика, без налогов, себестоимости и учёта движения денег.

Фильтр категории в статистике учитывает только позиции этой категории. Средний чек при таком фильтре - сумма выбранных позиций на один выполненный заказ с этой категорией. В реестре показывается полная сумма подходящего заказа; это объяснено под таблицей. Канал и статус относятся ко всему заказу. Количество заказов и диаграмма статусов учитывают все подходящие статусы.

Администратор создаёт, изменяет и удаляет заказы; каждое действие сохраняется в журнале. Аналитик просматривает реестр и статистику, выгружает CSV и PNG. Цена хранится в копейках в позиции заказа; изменение справочной цены не меняет прошлую продажу. При конфликте версии приложение просит перечитать запись.

## Проверки

```powershell
.venv\Scripts\python.exe -m ensurepip
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest tests/test_app.py -q
```

Для установки пакетов разработки требуется сеть; офлайн-набор содержит рабочие зависимости приложения. Серверные тесты работают на временной базе. browser_check.py требует Playwright и установленный Google Chrome; предварительно запустите демонстрационный сервер. Сквозной сценарий создаёт и удаляет тестовый заказ, оставляет его аудит и новый демонстрационный аккаунт. Протоколы выполненных проверок находятся в docs.

## Структура

backend - сервер, расчёты, доступ к БД и заполнение; frontend - оболочка SPA, стили и Canvas; database/migrations - SQL; tests - проверки; docs - документация, схемы, прототипы и снимки работающего приложения. Коллекция Postman доступна в frontend/static/postman_collection.json.

## Развёртывание

Для локальной демонстрации используется Flask без режима отладки. Для запуска через Waitress задайте SECRET_KEY длиной не менее 32 символов и выполните .venv\Scripts\python.exe manage.py serve. Сервер слушает 127.0.0.1:5065. Публичное размещение в комплект не входит. Для него отдельно нужны HTTPS, обратный прокси, безопасные cookie, закрытая регистрация сотрудников, резервное копирование и оценка нагрузки. Ограничение попыток входа хранится в памяти процесса и не заменяет общий ограничитель на шлюзе.
